# 📡 Radar System with SMS Alerts

An Arduino-based radar system that uses an ultrasonic sensor to detect objects and provides SMS alerts when an object is detected within a specified distance.

## 🚀 Features

- 📡 Ultrasonic-based object detection
- 🔄 Radar-style scanning
- 📱 SMS alert notification
- 📊 Real-time distance measurement
- 🤖 Arduino-based control system

## 🛠️ Components Used

- Arduino Uno
- Ultrasonic Sensor (HC-SR04)
- Servo Motor
- GSM Module
- Connecting Wires
- Breadboard
- Power Supply

## ⚙️ Working Principle

The ultrasonic sensor measures the distance of objects while the servo motor scans different angles. When an object is detected within the predefined distance, the system sends an SMS alert through the GSM module.
